# 🤖 AI College Enquiry Chatbot

A simple AI-powered chatbot that answers college-related questions instantly, built using HTML, CSS, and JavaScript.

**Live Demo:** https://mythrri.github.io/ai-college-chatbot/

## ✨ Features
- Instant replies to student queries
- Answers about Fees, Courses, Hostel, Placement, Admission
- WhatsApp-style chat interface
- Works on Mobile and Laptop
- No database or server needed - 100% Frontend

## 🧠 How It Works (AI Logic)
This project uses **Rule-Based NLP (Natural Language Processing)**:

1.  User types a question, e.g. "What is fees?"
2.  System converts text to lowercase and scans for keywords
3.  If keyword matches (fees, hostel, courses, placement), it triggers the relevant intent
4.  Bot returns a pre-trained response for that intent

Example:
`User: "hostel" -> Intent: Hostel Info -> Bot: "Hostel available..."`

This is the foundation of Intent Classification used in modern AI assistants like Alexa and Siri.
